# Извлечение цен с Ozon

## Когда применять

- Есть ссылка `https://www.ozon.ru/product/<slug>-<id>/` или `/product/<id>/`.
- Нужны цена, цена с Ozon Картой, наличие или рейтинг товара.
- Прямой запрос к Ozon отдаёт редирект-петлю или страницу «Похоже, нет соединения».

## Главное, что нужно знать

1. **ID товара — последнее число в URL** (`...-boho-731553575` → `731553575`).
2. **Ozon блокирует IP датацентров/ VPN.** Признак: `307` на `?__rr=1`, затем `403` с заголовком «Похоже, нет соединения» и текстом «Выключите VPN, перезагрузите роутер…» + incident ID. Заголовки, cookies и headless-браузер **не помогают** — блок по IP, а не по JS.
3. **Не перебирай зеркала** `m.ozon.ru`, `ozon.by`, `ozon.kz`, `ozon.com` — там тот же блок.
4. **Рабочий обход — Google Translate proxy** (см. шаг 1). Он ходит с других IP и отдаёт полный HTML карточки.

## Шаг 1. Скачать HTML карточки

```bash
ID=731553575
curl -sS -L --max-time 60 \
  -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0 Safari/537.36" \
  -H "Accept-Language: ru-RU,ru;q=0.9" \
  "https://www-ozon-ru.translate.goog/product/${ID}/?_x_tr_sl=auto&_x_tr_tl=en&_x_tr_hl=en&_x_tr_pto=wapp" \
  -o "/tmp/ozon-${ID}.html" -w "%{http_code} %{size_download}\n"
```

Шаблон хоста: `www.ozon.ru` → `www-ozon-ru.translate.goog` (точки заменяются дефисами).

Признаки успеха:

- HTTP `200`, размер ~500–900 КБ;
- `<title>` содержит название товара;
- в HTML есть `state-webPrice` и `application/ld+json`.

Если `429` («unusual traffic»):

- подожди **45–60 секунд**, смени User-Agent, повтори **один** раз;
- не делай параллельных запросов и не долби — иначе получишь CAPTCHA;
- сохраняй каждый ответ в отдельный файл, чтобы не потерять удачный HTML.

## Шаг 2. Извлечь цену
Используй скрипт который лежит рядом со skill.md в файле extract_price.mjs
```bash
node .claude/skills/extract-price/scripts/extract_price.mjs /tmp/ozon-731553575.html
```

Скрипт печатает JSON:

```json
{
  "productId": "731553575",
  "name": "…",
  "sku": "731553575",
  "regularPrice": "3 888 ₽",
  "cardPrice": "3 499 ₽",
  "currency": "RUB",
  "available": true,
  "rating": "4.9",
  "reviews": "337"
}
```

Если скрипт недоступен, цены лежат в трёх местах:

1. **JSON-LD** `application/ld+json`, `"@type":"Product"`:
   `offers.price` — обычная цена, `offers.priceCurrency`, `offers.availability`, `sku`.
2. **Виджет цены** `<div id="state-webPrice-…" data-state="…">` (HTML-сущности нужно раскодировать):
   - `cardPrice` — цена «С банками» (Ozon Карта / банки-партнёры);
   - `price` — обычная цена «С другими банками»;
   - `showOriginalPrice` — показывать ли обычную цену зачёркнутой;
   - `isAvailable` — наличие.
3. **Видимые элементы**: `tsHeadline600Large` — крупная цена (cardPrice), `pdp_bj2` — зачёркнутая обычная цена.

## Шаг 3. Правильно интерпретировать

| Поле | Что это | Подпись на странице |
|---|---|---|
| `offers.price` / `state.price` | обычная цена | «С другими банками» |
| `state.cardPrice` | цена с Ozon Картой | «С банками» |
| `showOriginalPrice: true` | обычная цена показана зачёркнутой | — |

- В ответе всегда указывай **обе** цены: иначе пользователь решит, что цена ниже, чем спишется без карты.
- JSON-LD отдаёт **регулярную** цену, а не цену с картой.
- `isAvailable: false` или `OutOfStock` — товара нет в наличии; цену всё равно можно указать как справочную.

## Подводные камни

- **Варианты товара.** В HTML десятки `"price"`/`"originalPrice"` от других цветов/камней. Доверяй только JSON-LD с `sku`, совпадающим с ID из URL, и **первому** `state-webPrice` (выбранный вариант). Не бери цены из блока «похожие товары».
- **Регион и аккаунт.** Цена и наличие могут отличаться от того, что видит пользователь. В конце ответа добавь: «данные на <дата>; цена может зависеть от региона и аккаунта».
- **Рассрочка.** «Оплатить позже без %» — не цена товара, не путай.
- **Не выдумывай.** Если HTML не содержит `state-webPrice` и JSON-LD, скажи, что цену получить не удалось, и укажи причину (429/403/капча).

## Проверка перед ответом

1. `name`/`<title>` соответствует товару из ссылки.
2. `sku` == ID из URL.
3. `offers.price` совпадает с видимой ценой «С другими банками».
4. Указана дата получения данных.

## Формат ответа
```
объект { regular_price, sale_price, has_credit } (обычная цена; цена с Ozon Картой; всегда false для рассрочки)
```

## Что не сработало (не тратить время)

- `r.jina.ai` для Ozon → `451 Unavailable For Legal Reasons`.
- CORS-прокси `allorigins.win`, `codetabs.com` → таймауты (датацентровый IP).
- Wayback Machine → для товарных карточек Ozon снимков обычно нет.
- Google/Bing/Yandex по ID товара → ID не индексируется; поисковики бесполезны для цены.
- Headless Chrome напрямую → та же страница «нет соединения», потому что блок по IP.
